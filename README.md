# High-Yield Stablecoin Sim (Higher Risk)

Public dashboard for Justin's **higher-risk** paper-trading stablecoin yield simulation, targeting about 12% blended APY.

- No real funds, wallets, or transactions.
- Completely separate from the [low-risk book](https://jtncr.github.io/yield-sim-dashboard/).
- Regenerated and pushed on every simulator `update` cycle.
- Live page: https://jtncr.github.io/yield-sim-highrisk-dashboard/
